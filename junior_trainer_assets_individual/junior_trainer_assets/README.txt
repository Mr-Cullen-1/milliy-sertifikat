# Junior Trainer — individual visual assets

Assets were cropped individually from the supplied sprite-sheet image.

- Format: PNG
- Background: white, retained from the source sheet (not transparent)
- Includes: mascot poses, math symbols, learning/game icons, rewards, shapes and decorations.
- Note: some crops may include a small amount of neighboring white space or edge pixels because the source was a single collage. Please review before production use.

For responsive web use, render assets with `max-width: 100%; height: auto; object-fit: contain;`.
